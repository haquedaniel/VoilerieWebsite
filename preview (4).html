l’expérience signature

Une petite barque pour vivre le Goyen autrement.

La barque est mise à disposition comme un extra gratuit pour les visiteurs du Clos de la Voilerie, uniquement lorsque les conditions météo et de marée le permettent.

Avant d’afficher le code du cadenas, merci de lire les règles d’utilisation. Elles sont simples, mais importantes : l’estuaire reste un vrai milieu marin.

  • Utilisation uniquement par temps calme et de jour.
  • Gilets de sauvetage obligatoires pour tous les occupants.
  • Les enfants doivent toujours être accompagnés par un adulte.
  • Ne pas utiliser la barque après consommation d’alcool.
  • Vérifiez la météo, la marée et le courant avant toute sortie.
  • La barque doit être ramenée, attachée et verrouillée après utilisation.
Code cadenas : 0000

Remplacez 0000 par le vrai code avant publication, ou contactez-nous pour l’obtenir si vous préférez ne pas l’afficher ici.

règlement intérieur

Quelques règles simples pour le confort de tous

  • Merci de respecter le calme de la résidence, notamment le soir et tôt le matin.
  • Le logement est non-fumeur.
  • Merci de fermer les fenêtres, éteindre le chauffage et couper les lumières lors de vos absences.
  • Les déchets doivent être déposés dans les bacs prévus à cet effet.
  • En cas de casse ou de problème, prévenez-nous rapidement pour que nous puissions intervenir.
  • Le ménage de sortie est prévu, mais le logement doit être laissé dans un état raisonnable.
